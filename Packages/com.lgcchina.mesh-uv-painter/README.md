# LGC 网格UV绘画工具 v2.7.0

Unity 2022.3 编辑器工具。入口：**LGC > LGC网格UV绘画工具（GPU）**。

v2.7.0 重点修复合并 FBX 中多个材质共用一套网格时的 UV 混合问题。工具会按当前 Renderer 材质槽和 Mesh 子网格确定 UV 范围，不再默认显示整张 Mesh 的全部 UV。

## v2.7.0 材质 UV 范围

- 默认模式为 **当前材质组**：只显示当前材质槽对应的子网格 UV。
- 同一个 Material 被多个子网格使用时，这些子网格的三角形会合并为同一活动材质组。
- UV 叠加线、UV 边界限制、孤岛识别、孤岛填充和孤岛橡皮擦统一使用当前材质组的三角形。
- **全部子网格（仅查看）** 会弱化显示其他材质 UV，便于比较整体布局；绘制仍限制在当前材质组。
- 多个不同 Material 共用同一主贴图时，UV 叠加设置中会显示共用贴图警告。此时重叠 UV 区域仍可能互相影响，最稳妥的做法是按材质拆分贴图。

## 安装

推荐通过 VCC / ALCOM 安装：

1. 在 VCC / ALCOM 添加 LGC VRC Packages 合集：<https://lgcchina.github.io/LGC-VRC-Packages/index.json>。
2. 为 Unity 2022.3 项目安装 **LGC网格UV绘画工具**（`com.lgcchina.mesh-uv-painter`）。
3. 等待 Unity 编译完成，从 **LGC > LGC网格UV绘画工具（GPU）** 打开。

手动安装时，将包目录放在项目的 `Packages/com.lgcchina.mesh-uv-painter`，或解压发布 ZIP 到 Assets 下的独立工具目录。保留 `.meta`，不要同时保留两份脚本副本。

## 使用流程

1. 将包含 `MeshRenderer` 或 `SkinnedMeshRenderer` 的对象拖入“网格对象”。
2. 在“材质槽”选择身体、眼睛等需要编辑的材质槽。
3. 在“UV叠加设置 > UV显示范围”中保持 **当前材质组**，确认 UV 线只显示该材质对应的区域。
4. 使用画笔、橡皮擦、孤岛填充或孤岛橡皮擦进行编辑。
5. 通过“保存与导出”输出完整贴图或透明绘画层。工具关闭时会恢复临时材质实例。

## 现有功能

- 3 RenderTexture 架构：原图、绘画层、预览层分离。
- 画笔、橡皮擦、UV 孤岛填充、孤岛橡皮擦和图案盖印。
- 对称绘画、UV 边界扩展、孤岛隔离、撤销与重做。
- 中、日、英三语界面。
- 输出目录定位、完整贴图保存、透明绘画层导出和白底导出。

## 常见问题

**选择材质槽后 UV 为空**

该槽位可能没有对应 Mesh 子网格，或子网格索引超出了 Renderer 材质槽数量。先确认 FBX 导入后的材质槽与子网格映射，再点击“刷新/重新读取当前槽”。

**“全部子网格”下看起来仍然重叠**

这是预期行为。全部子网格只用于查看整体 UV 分布，其他材质 UV 会弱化显示，但绘制和遮罩仍按当前材质组处理。

**两个材质看起来共用同一张贴图**

若工具显示共用贴图警告，说明不同材质槽引用了同一主贴图资产。按材质拆分贴图后才能彻底避免重叠 UV 区域互相污染。

**工具是否修改原模型、材质或贴图**

不会直接改写源资源。绘制使用内存中的材质实例和输出 PNG；具体保存结果以“保存与导出”写出的文件为准。

## 测试重点

- 单材质模型：UV 线与绘制行为应与旧版一致。
- 身体、眼睛使用不同材质且 UV 重叠：当前材质组应只显示所选材质 UV。
- 同一 Material 映射多个子网格：活动 UV 应为这些子网格的并集。
- 多个材质共用同一主贴图：应出现共用贴图警告。
- 切换材质槽、刷新材质槽和切换 UV 显示范围后，UV 线及孤岛填充范围应立即更新。
