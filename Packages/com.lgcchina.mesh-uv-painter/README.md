# LGC 网格UV绘画工具 v3.0 beta

Unity 2022.3 编辑器工具。入口：**LGC > LGC网格UV绘画工具（GPU）**。

## v3.0 beta（3.0.0-beta.1）多色渐变与 UV 操作简化

- 渐变改为 Unity 原生色带编辑器（与粒子生命周期颜色使用相同的色标交互），支持增减颜色/透明度色标、调整位置百分比、混合/固定模式及整体反转。每类最多 8 个色标，遵循 Unity 编辑器限制。
- 移除渐变与渐变擦除的独立预览开关，统一使用绘制目标区“实时预览效果”。关闭时不显示待应用渐变；应用操作仍可写入，导出仍仅包含已应用内容。
- 监听原生渐变弹窗中的颜色、透明度和位置变化，更新待应用预览；渐变 GPU 输出刷新后主动重绘 SceneView，修复复用同一预览贴图时模型显示滞后。继续遵守 UV 孤岛、UV 选区、绘制选框与禁用保护。
- 画笔尺寸模式移到常规画笔/橡皮擦设置顶部；对称选项使用独立边框卡片。
- UV 操作合并为“隐藏/显示所选”和“禁用/恢复所选编辑”两个动态按钮，再次点击切换；混合状态先统一隐藏/禁用，再点击统一恢复。
- “只显示所选”和“只编辑所选”并排放入聚焦区域，可分别启用或同时启用。只显示使用临时视图遮罩，关闭后恢复先前手动显隐状态；清除选择同时退出聚焦，避免空选区锁住工具。提供“恢复全部显示与编辑”统一重置。

安装：覆盖项目本地 Packages/com.lgcchina.mesh-uv-painter，保留 .meta，等待 Unity 2022.3 编译并重新打开窗口确认 v3.0 beta。GitHub Release 标记为预发布；VCC/ALCOM 如未显示此版本，请启用预发布包，或手动安装 Release ZIP。

注意：渐变弹窗失焦时仍跟踪色标变化；未应用预览不增加撤回记录，也不会进入导出。关闭全局实时预览会恢复模型原材质。

## v2.12.0 UV 三角面框选与绘制内容变换

### 更新内容

- UV边界移除“绘制”选择模式，保留孤岛与框选；绘制操作回到绘制 Tab。UV 框选按矩形与三角面的相交关系选中完整面，覆盖顶点包含、矩形包含及边交叉；公共顶点周围的小框可一次选中相接的 6 个面。
- Shift 加选、Ctrl/Command 减选按三角面成员处理，再重建绿色高亮，不会把相邻面从矩形中截断。隐藏、禁用、只编辑所选继续使用 UV 选区。
- 绘制 Tab 新增“框选”，使用独立像素选区，可选择已有绘制或空白区域，支持 Shift 多框追加、Ctrl/Command 减选。选区保留并限制后续画笔、橡皮擦、填充、盖印、渐变及内容镜像；在框选工具点击“取消选择”恢复全区绘制。
- 框选后切换移动、旋转或缩放，在选区内左键拖动；也可输入像素位移、角度、横纵缩放。变换以选区包围盒中心为轴，旋转和缩放按工作贴图像素计算，支持非方形贴图。
- 变换为剪切移动，保留未选中的绘制和原贴图。实时预览通过独立 RT 和不可变源采样，透明度感知插值减少黑边；点击“应用变换”写入并产生一次撤回，Esc/取消/切换模式或 Tab 放弃待确认结果。支持撤回重做，选区状态本身不进入绘画历史。
- 新增选区“孤岛填充”：先框选，切换孤岛填充后点击目标 UV 孤岛，只填充该岛与绘制选区的交集。填充与变换均遵守隐藏/禁用、UV 边界和只编辑所选保护；变换允许移动到原绘制选区以外的可编辑位置。
- 独立选区随绘制精度变化缩放；输入捕获处理画布外松键、Escape 和失焦，保留画布尺寸、底部输出和盖印行为。

## v2.11.0 绘制精度、渐变挑染与 UV 区域

- 绘制 Tab 新增“绘制清晰度”滑条：原图 / 1024 / 2048 / 4096（长边，保持比例），点击“应用绘制精度”调整真实工作贴图尺寸。细节请先提高精度再绘制；笔刷采用亚像素中心和四点边缘采样，减少细笔触抖动与锯齿。
- 切换精度保留并缩放绘制层、选区、隐藏和禁用状态；已有低分辨率像素不会凭空变清晰。跨分辨率的撤回/重做仍可使用，恢复时按当前工作尺寸采样。
- 历史快照总预算 256 MiB，最多 50 步；4096 方图通常保留 4 张历史快照，撤回与重做合计计入预算。池内限制保留小贴图，高分辨率快照及时释放；画布和临时预览仍有额外显存开销。
- 绘制模式新增“渐变”：左键拖出方向，拖动两端圆点调整。起终点支持颜色与透明度，可交换颜色或将终点设透明，支持不透明度、实时预览、应用和撤回。
- 有 UV 选区时渐变只作用于选区；没有选区时，启用孤岛隔离会限制到起点所在孤岛。渐变同时遵守 UV 边界、隐藏/禁用和“只编辑所选区域”，支持已锁轴的对称渐变。未应用预览不进入导出或绘画历史。
- UV边界 Tab 新增“UV选择与保护”，默认孤岛选择模式。悬停黄色高亮、点击绿色选中，Shift 追加、Ctrl/Command 取消；可切回“绘制”模式恢复画布绘画。
- “框选区域”按矩形与 UV 覆盖范围的交集选择，可截取连成一体孤岛中的一个面或局部区域。支持拖动、追加、取消以及 Escape/失焦结束交互。
- 提供隐藏所选、显示所选、只显示所选、禁用所选、恢复所选编辑、取消选择、显示全部及恢复全部编辑。“只编辑所选区域”用于限定后续画笔、橡皮擦、填充、盖印、渐变和内容镜像。
- 隐藏只在工具画布遮住内容和 UV 线，隐藏/禁用区域均阻止后续局部编辑，不删除绘制，不影响模型预览或导出；全局“清空本次修改”和撤回/重做仍按原本的整层语义工作。

### 推荐测试流程

1. 先将绘制清晰度设为 4096 并应用，再画细笔触；导出分辨率也选 4096。默认“原图分辨率”依然按原始贴图尺寸输出。
2. 在 UV边界中悬停和点击孤岛；也可框住一束头发或连通展开图的一个面，勾选“只编辑所选区域”。
3. 回到绘制 Tab，选择渐变，拖出发根到发尾方向，设置颜色/透明度并应用。测试撤回、禁用区域和导出。

容易踩的坑：脚本重载、关闭窗口和切换目标/材质会丢失尚未导出的绘制及选区状态；提高工作精度不会重建旧笔触的细节。只编辑所选区域在未选中任何像素时会阻止绘制。完全重叠 UV 不能独立绘制或选择对应的不同三维面；当前孤岛沿用 UV 像素连通识别，相接或重叠 UV 会被视为同一岛。框选为矩形像素范围，不是三维面的自动识别。

## 使用流程

1. 将包含 `MeshRenderer` 或 `SkinnedMeshRenderer` 的对象拖入“网格对象”，选择材质槽。
2. 选择画笔、橡皮擦、孤岛填充、孤岛擦除或盖印，左侧会显示对应参数。
3. 画笔默认按屏幕半径工作。滚轮放大、中键拖动或 Alt + 左键拖动画布，使用 `[` / `]` 调整笔刷半径。
4. 如需对称，启用对称绘画，拖动轴线或端点，点击 **锁定并开始绘画**。盖印使用“对称盖印”时也需要先锁轴。
5. 打开左侧绘制目标区的 **实时预览效果**，在模型上查看结果。绘画撤回使用左侧底部按钮或工具窗口中的 Ctrl/Cmd+Z；重做使用 Ctrl/Cmd+Y 或 Ctrl/Cmd+Shift+Z。
6. 通过左侧底部的 **输出** 保存完整 PNG 或导出绘画层，可选白底。关闭实时预览、切换对象/材质槽或关闭窗口时恢复原材质。

## 材质组 UV 范围

- 默认 **当前材质组** 只显示当前槽对应的子网格 UV。同一 Material 对应多个子网格时，活动范围为它们的并集。
- UV 叠加、边界限制、孤岛识别、孤岛填充和擦除统一使用当前材质组。
- **UV边界 > UV叠加设置 > 全部子网格（仅查看）** 会弱化显示其他材质 UV，绘制仍限制在当前材质组。
- 不同材质共用同一主贴图时会显示警告；重叠 UV 仍可能互相影响，应按材质拆分贴图。

## 容易踩的坑

- Unity 菜单或其他窗口中的撤销属于 Unity 全局历史；画布撤回属于工具的绘画历史，两者彼此独立。全局撤销之后，开启中的实时预览会在下一次编辑器更新恢复绑定。
- 对称轴未锁定时暂停绘画及盖印应用，先点击“锁定并开始绘画”。重新调轴或重置轴后，需要再次锁定。
- “屏幕半径”以 Unity 界面坐标像素计算。极端放大、很小的半径受贴图本身分辨率限制，最小有效半径为半个贴图像素，光标会反映该限制；高 DPI 下界面像素不等于显示器物理像素。
- 盖印按 UV 比例缩放，不使用画笔尺寸模式。盖印的移动、旋转、缩放和删除是应用前的预览操作，点击“应用盖印”才写入绘画历史。
- “清空绘画”只清空当前绘画层，可立即撤回；切换对象、刷新/切换材质槽或脚本重载会重新读取目标，并清空本次未导出的绘画及历史。先保存重要结果。
- 保存场景时会先恢复原材质，再在下一次编辑器更新恢复预览，避免场景保存临时材质引用。
- 临时预览不直接改写原材质或原贴图。保存完整贴图只输出 PNG，不自动给原材质更换贴图。
- 材质槽无对应子网格时，UV 为空属于预期行为。先确认 FBX 材质槽与子网格映射。
