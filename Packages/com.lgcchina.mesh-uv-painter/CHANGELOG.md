# LGC 网格UV绘画工具修改日志

## v2.7.0 - 2026-11-12

### 更新内容

- 新增按材质组隔离 UV：默认只显示当前材质槽对应的 Mesh 子网格 UV。
- 同一 Material 映射多个子网格时，自动合并这些子网格的三角形作为活动材质组。
- UV 叠加线、边界遮罩、孤岛识别、孤岛填充和孤岛橡皮擦统一使用当前材质组，修复身体与眼睛等不同材质 UV 混合的问题。
- 新增“全部子网格（仅查看）”显示范围。其他材质 UV 以弱化颜色显示，绘制与遮罩仍限制在当前材质组。
- 新增共用主贴图检测：不同材质槽实际引用同一主贴图资产时显示风险提示。
- UV 叠加缓存增加三角形数组引用校验，切换材质或显示范围时不再复用旧 UV 线。
- 窗口、脚本注释、`package.json`、README 与 CHANGELOG 同步为 `v2.7.0` / `2.7.0`。

### 安装方式

1. 通过 VCC / ALCOM 的 LGC VRC Packages 合集安装 `com.lgcchina.mesh-uv-painter`。
2. 等待 Unity 2022.3 编译完成。
3. 从 **LGC > LGC网格UV绘画工具（GPU）** 打开。

手动安装时，将包目录放在 `Packages/com.lgcchina.mesh-uv-painter`，保留 `.meta`，并移除其他重复脚本副本。

### 容易踩的坑

- “全部子网格（仅查看）”只改变 UV 线的查看范围，不会把绘制范围扩展到其他材质。
- 材质槽必须有对应 Mesh 子网格；材质槽存在但无对应几何体时，活动 UV 为空属于预期结果。
- 两个不同 Material 即使颜色或贴图外观相似，只要没有引用同一主贴图，就不会触发共用贴图警告。
- 共用同一主贴图的不同材质仍可能污染重叠 UV 区域；该提示不能替代按材质拆分贴图。
- 切换材质槽或点击“刷新/重新读取当前槽”后，应重新确认 UV 显示范围是否符合预期。

### 测试重点

- 单材质模型回归。
- 身体与眼睛使用不同材质、UV 重叠的合并 FBX。
- 同一 Material 映射多个子网格。
- 多个不同 Material 共用同一主贴图。
- 当前材质组与全部子网格之间反复切换。
